# Firmware

The active Minew port is in `port/`; the MCUboot/UF2 work is in `bootloader/`.

Start with the root `README.md`, `docs/build.md`, and `docs/testing.md`. Exact west dependencies are in `manifest-frozen.yml`; ZMK itself is pinned by `scripts/setup-port.sh`. Upstream clones, toolchains, private signing keys, memory backups, compiled output, and raw local logs are excluded from this public repository.
